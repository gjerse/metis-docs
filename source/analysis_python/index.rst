    Analysis with Python
    ====================
 
    This section contains the code used to analyse Metis data in Python:
    reusable functions, recommended recipes, and the reference for the
    ``metis-tools`` package.
 
    It assumes you already have the data. If you do not, start from
    :doc:`/data/data_access_python`.
 
    .. note::
 
       Short, runnable end-to-end scripts live in the
       :doc:`/auto_gallery/index`. This section explains what the code does
       and why, and documents the functions it calls.
